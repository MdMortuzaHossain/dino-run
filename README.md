# Dino Run

## [▶ Play Dino Run](https://mdmortuzahossain.github.io/dino-run/dist/)

Click the link above, then press **Start running**. No download needed.

A small, original pixel-art dinosaur endless runner, inspired by the classic offline browser game. Built with vanilla HTML, CSS and JavaScript. No build tools needed.

## Play

Open `dist/index.html` in a modern browser. Space / Up: jump. Down: duck. P / Escape: pause. On a phone, tap the game or use the Jump and Duck buttons. Sound is optional. Best score is saved in your browser when storage is available.

## GitHub Pages

Upload the contents of `dist` to the root of your GitHub repository. In repository Settings → Pages, choose Deploy from a branch, then main and / (root). Alternatively keep this project structure and use a Pages workflow that publishes `dist`.

## Modify

`dist/game.js` contains physics, obstacles and canvas artwork; `dist/style.css` contains the page design. All gameplay works offline; the optional Google Fonts request falls back to system fonts.
